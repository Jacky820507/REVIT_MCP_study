# 施工架算量

在 RevitMCP 中執行施工架數量計算時使用此 Skill。

## 工作流程

1. 針對 `室外框式施工架(含防護設施)`，優先採人工描繪，並執行 `calculate_selected_detail_line_perimeter`。
   - 先請使用者選取已描繪好的 detail line 或 filled region 邊界。
   - 這是較可信的室外數量路徑，因為使用者可以直接目視確認外周長。
   - 只有在使用者要算 `周長 * 高` 面積時才帶入 `scaffoldHeightMm`。
   - 若使用者要算地下室外牆防水毯，可沿用此室外外部周長作為周長來源，但高度必須改用各地下層樓高或圖說指定防水高度，不直接沿用施工架高度。

2. 針對室內房間施工架，執行 `calculate_room_scaffold_perimeters`。
   - 納入已放置的 Rooms。
   - 排除樓層 `FN` 與 `TF`。
   - 除非使用者另外指定，否則使用預設排除字詞。
   - 回報時同時寫清楚公式與單位，避免周長、面積與體積混在一起。

## 室內規則

一般施工架 `室內施工架(含防護措施)`:
- 適用範圍：不是樓梯/電梯類房間，且未被排除字詞或排除樓層命中的 rooms。
- 公式：`周長 * 高`。
- 輸出欄位：有高度時使用 `GeneralScaffold.QuantitySqM`；`AuditPerimeterM` 只作周長檢核。

室內裝修施工架 `室內裝修施工架`:
- 適用範圍：房間名稱或編號包含 `安全梯`、`無障礙梯`、`樓梯`、`電梯`、`貨梯`、`昇降機`、`升降機` 或 `客梯`。
- 公式：`長 * 寬 * 高`；長寬採 Room boundary 的最小面積定向包絡尺寸。
- 輸出欄位：使用 `InteriorFinishScaffold.QuantityM3`。

排除房間：
- 排除房間名稱或編號包含 `戶外平台`、`戶外平臺`、`室外平台`、`室外平臺`、`屋頂平台`、`屋頂平臺`、`露臺`、`露台`、`陽台`、`陽臺`、`管道間`、`水箱` 或 `挑空`。
- 排除樓層的優先序高於房間關鍵字。位於 `FN` 或 `TF` 的房間，就算包含 `電梯` 也仍然排除。
- `梯廳` 仍是一般室內房間，不可因含有 `梯` 字就改列室內裝修施工架。
- 施工架不扣門窗開口。

## 既有工項 Excel

當使用者要更新 `綜合大樓工項-0615.xls` 類型的活頁簿：

1. `室內施工架 Excel` 先讓使用者選 Excel 與空間明細分頁，並在同一次執行中完成空間表更新；再以該分頁房號作施工架名單，周長引用該分頁的 Finish 周長。不得固定綁定 `01空間表` 名稱，也不要沿用 `內牆!K144` 手動挑列加總。
2. 高度必須由目前 Revit 幾何重新判定，不可直接沿用 `內牆` 分頁欄位：一般室內房間先找覆蓋 Room 的實體天花，沒有實體天花才採上層樓板底；樓梯／電梯類的室內裝修施工架不採天花。樓梯／電梯 Room 應先找 XY 投影至少 50% 重疊的最近上方同類 Room，以其 Level 樓板底作垂直分段終點；中間沒有放 Room 時跨層延伸，找不到上方重疊 Room 才採 Room `上限`。`上限` 無效時，優先選同棟且實際有 Room 的較高 Level，不得依全專案標高誤抓其他棟的 GL／樓層。實體天花以幾何射線或 bbox 高度為主，不可只因 Ceiling `LevelId` 與 Room `LevelId` 不一致就排除；若射線取樣漏掉但天花 XY bbox 明確覆蓋 Room，且高度有效、不超過名目上層樓板底太多，可採用該天花並列 ElementId 與重疊證據。同一房間範圍有不同高度或不同類型天花時，先以 Room `天花板塗層` C 代碼篩選房間內候選，再採向上最先遇到的最低底面；不得以接近名目樓高者優先。Room 未填 C 代碼時仍採最低有效底面，排除候選需列類型與 ElementId。Room 的負 `基準偏移` 通常只是空間體積向下延伸，不應把施工淨高基準往下拉；一般淨高仍以 Room 所屬 Level 標高起算，正偏移才視情況納入。幾何射線不可用時，才以 `上層樓層標高 - 代表樓板厚度 - 房間基準標高` 備援；Room bounding-box 是最後備援且必須警告。
3. 建立 `施工架計算` 稽核分頁時保留摘要列，先刪除第 9 列以下的舊明細與樓層小計，再依本次房間清單完整重建，避免房間增減後殘留舊列。逐房列出分類、公式、來源、單位與精簡備註。備註欄只保留可行動問題：Revit/Excel 房間對不上、重複房號、缺周長、缺高度、長寬不足、房名不一致、包絡面積異常或 Room 高度備援。不要把正常高度來源、實體天花名稱、樓梯／電梯採樓板底、垂直堆疊依據等過程資訊塞進備註；這些應由高度來源欄與稽核資料承擔。
4. dry-run 後確認，先做 timestamped backup，再更新 `其他面積`；必要公式鏈為 `施工架計算 → 其他面積 → 小計`。
5. 先讀取範本的實際工項列與公式方向。`物流中心工項-0720.xls` 以 `小計` 保存三個工項，`其他面積` 回連名稱與編號；不得反向假設 `更新工項` 一定有完整工項。
6. `更新工項` 視為選用分頁：只同步已存在的對應列。缺少室外或室內裝修施工架列時不報錯，也不強制插列。
7. `其他面積` 的一般室內施工架若是多列樓層區塊，應找出起訖列，但樓層名單必須取自每個 Revit Room 的 `Level`，不可由模板 D 欄反向限制專案。依 `floor-level-ordering` 規則排序：地下層由深到淺、地上層由低到高、屋突層由低到高且 `RF` 在最後。依偵測結果重寫 D 欄；列數不足時在下一工項前插入同格式列，多餘模板列清空。所有長、寬、高與乘法只保留在 `施工架計算`，並在 `施工架計算` 建立樓層小計欄；`其他面積` 使用列的 E 欄固定為 1，F:H 清空，I 欄以公式引用該樓層小計，P 欄直接引用 `施工架計算` 的工項摘要。禁止再以 `G=H/F`、`I=H×E`、`SUMIFS`、挑列公式或 `P=SUM(I:I)` 重算，避免模板殘值造成二次相乘。
   - 樓層前若含棟別前綴，須先依 `floor-level-ordering` 判斷並移除棟別；例如 B 棟的 `B-1F` 應輸出為 `1F`，不能誤判為地下 `B1F`。
   - 逐房 O 欄既然使用 `ROUND(...,3)`，dry-run 預期值、樓層小計與總計也必須採「逐房先取 3 位再加總」；不可用「未取位總和後再取位」驗證。
   - `施工架計算!B5:B6` 摘要格必須是直接彙總逐房 `O` 欄的 `SUMIFS` 公式：B5 篩 `分類代碼=general_scaffold` 且 `計入=是`，B6 篩 `分類代碼=interior_finish_scaffold` 且 `計入=是`。不可直接塞常數，也不可只用難追溯的輔助欄加總。
8. 缺少 `室內裝修施工架` 時，至少在 `小計` 與 `其他面積` 插列並保留格式，單位 M3。
9. UI 只保留一顆 `室內施工架 Excel` 按鈕；按鈕內依序執行「選空間分頁 → 空間表更新 → 重建施工架計算 → 更新其他面積與小計」，並同步刷新一般室內 M2 與室內裝修 M3。Excel 內部工項名稱仍用 `室內施工架(含防護措施)` 與 `室內裝修施工架`。
10. `01空間表` 重複房號要直接中止；寫入後先完整重算，驗證必要公式鏈並掃描 Excel error token，通過才儲存。
11. 舊值若由 Excel COM 回傳成約 `-214682xxxx` 的 CVErr/HRESULT，視為 `#REF!` 等公式錯誤，不得當成數量顯示。
12. Excel COM 的活頁簿、Application 與 RCW 釋放要放在 `finally`；不可留下隱藏 `EXCEL.EXE`，也不可用終止所有 Excel 行程作為一般清理手段。
13. pyRevit 共用 `lib` 模組可能被 IronPython 快取；按鈕腳本應在 `import scaffold_excel` 後 `reload(scaffold_excel)`，並在核心模組錯誤訊息放入版本碼，避免 UI Reload 後仍執行舊程式。
14. Excel 分頁搜尋可以忽略名稱前後空白，但寫跨分頁公式時必須保留 `Worksheet.Name` 原始字串。像 `其他面積 ` 尾端空白是名稱的一部分，公式必須寫成 `='其他面積 '!P29`，不可先 `strip()` 成 `其他面積`。
15. 驗證直接寫入的 Excel 數值是否為常數時，使用 `Range.HasFormula`，不可用 `Formula` 是否為空判斷；Excel COM 的 `Formula` 對常數格可能直接回傳該數值。

## 回報方式

回報結果時：
- 明確列出公式，尤其是 `室內裝修施工架`。
- 室內裝修列請寫成 `長 * 寬 * 高 = 數量`。
- 一般施工架列請寫成 `周長 * 高 = 數量`。
- 周長檢核值要和最終數量分開。
- 高度來源必須逐房標示為實體天花、上層樓板底、樓層板厚備援或 Room bounding-box 備援；樓梯／電梯類若出現天花高度即視為錯誤。
- 同一房間若有多片重疊天花，核對採用者的 C 代碼與 Room `天花板塗層` 一致；同碼候選採最低底面，並在警告列出排除的 ElementId。
- 樓梯／電梯高度需列出上方重疊 Room 的 ElementId、Level 與重疊率；中間缺 Room 時跨層延伸，多棟 Level 交錯時只採同棟候選。
- 室內裝修施工架必須逐房計算 `長 × 寬 × 分段高度`；禁止用各層房間面積總和乘整棟高度。
- 更新既有活頁簿時，回報 `01空間表` 有但 Revit 無對應、Revit 有但 `01空間表` 未列、缺少高度與排除房間筆數。
- 檢查 `施工架計算 → 其他面積 → 小計` 不得出現 `#REF!`；`更新工項` 僅檢查實際存在的施工架列。
- 檢查 `施工架計算!B5:B6` 是公式，且公式直接引用逐房明細 `O` 欄、分類 `E` 欄與計入 `Q` 欄。
- `其他面積` 樓層列不足時，依 Revit 房間 `Level` 自動插入並保留格式；不得要求樓層符合固定 B1F、1F、2F 模板，也禁止靜默併入其他樓層。
- `長×寬` 比 Room 面積大 10% 以上且差逾 0.5 m2 時，標記旋轉／不規則房間供人工確認。
- 若同時牽涉地下室外牆防水毯，要明確分開回報：施工架是 `外部周長 * 施工架高度`，防水毯是 `地下層外部周長 * 樓層高度/防水高度`。
- `FN` 在施工架與地下室外牆防水毯分層高度中不列入地下層；但若議題是大底防水，`FN`/筏基/基礎底版需依 `domain/floor-area-review.md` 納入水平投影聯集。
