# 樓層排序

## 核心規則

所有報表與資料表只要出現樓層列，預設依下列建築閱讀順序排列：

1. 地下層：`FN` 若明確要列入時排在最深層；一般樓層排序為 `B5F → B4F → B3F → B2F → B1F`，也就是數字越大越先列。
2. 地上層：`1F → 2F → 3F → ... → 10F → 11F`，用數值排序，不用字串排序。
3. 屋突層：`R1F → R2F → ... → RF`，`RF` 排在所有 `R#F` 之後。
4. 未能解析的樓層排在最後，保留原始名稱並標示需人工確認。

## 正規化

排序前先把樓層名稱轉成排序鍵：

- 去除空白、底線、連字號與 `樓層`、`樓` 等描述字。
- `B01F`、`B-1F`、`B1` 正規化為 `B1F`。
- `01F`、`1樓`、`1F` 正規化為 `1F`。
- `R01F`、`R-1F` 正規化為 `R1F`。
- `RF` 保留為 `RF`。
- 若同一專案出現 `B-B1F`、`B-R1F` 等可確認的棟別前綴，先移除共同棟別再解析：`B-B1F → B1F`、`B-1F → 1F`、`B-R1F → R1F`。不可把棟別 `B` 誤當地下層代碼。

不要用 Excel 原本列順序、字母排序或範本固定列定義專案樓層。樓層名單應來自 Revit 目前專案的 Room/Level 或當次資料來源。

## Excel 報表

- 插入或更新樓層列時，先依本規則排序，再寫入 Excel。
- 若模板列不足，應插列並保留格式；多餘模板列清空，不可把數量併到相近樓層。
- 若正式數量來自明細分頁，彙總分頁應以公式引用明細小計欄位，例如 `='施工架計算'!W10`；避免只填常數造成來源不透明。
