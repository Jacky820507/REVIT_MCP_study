# 專有／共用分類與面積類型

## 這份文件要解決的問題

面積計畫做完之後，每個 Area 還要回答兩個不同性質的問題：

1. **它是專有還是共用？** —— 法律問題，依公寓大廈管理條例。
2. **它的 Area Type 是什麼？** —— Revit 內建屬性，只存在於特定面積計畫。

兩者常被混為一談，但**資料來源、判定依據、可自動化的程度完全不同**，混用會讓
一個看起來合理的分類表其實沒有法律意義。

---

## 一、法定定義（公寓大廈管理條例 §3）

逐字引用，這是判定的唯一依據：

| 用語 | 法定定義 |
|---|---|
| **區分所有** | 指數人區分一建築物而各有其專有部分，並就其共用部分按其應有部分有所有權。 |
| **專有部分** | 指公寓大廈之一部分，**具有使用上之獨立性**，且為**區分所有之標的**者。 |
| **共用部分** | 指公寓大廈專有部分**以外**之其他部分及不屬專有之附屬建築物，而**供共同使用**者。 |
| **約定專用部分** | 公寓大廈**共用部分**經**約定**供特定區分所有權人使用者。 |
| **約定共用部分** | 指公寓大廈**專有部分**經**約定**供共同使用者。 |

### 從定義直接推導出的三條規則

**規則 1：共用是「剩下的」，不是一份清單。**
條文把共用定義成「專有部分以外之其他部分」。所以正確的判定順序是**先認定專有，
其餘為共用**，而不是拿一份「共用空間清單」去比對。任何以關鍵字清單判定共用的
做法，本質上都是在猜測專有的補集。

**規則 2：約定專用／約定共用不可能從模型判定。**
兩者的定義裡都有「**經約定**」。約定來自規約或買賣契約，模型裡沒有這個資訊。
工具**不得**自行把任何 Area 標成約定專用或約定共用——只能提供欄位讓人填。

**規則 3：專有的判準是「使用上之獨立性」＋「區分所有之標的」，不是用途名稱。**
一個叫「儲藏室」的空間可能是專有（登記在某戶名下）也可能是共用（全棟共同使用）。
名稱只是線索，不是判準。

---

## 二、可自動化到什麼程度

| 判定 | 可自動化 | 理由 |
|---|---|---|
| 建議分類（專有／共用） | **建議，不決定** | 名稱關鍵字只是線索；最終認定取決於區分所有登記 |
| 約定專用／約定共用 | **不可** | 定義即為「經約定」，模型無此資訊 |
| 大公／小公 | **半自動** | 非法定用語，是實務慣例；可依「服務範圍是全棟或單層」推定 |
| Area Type | **可** | Revit 內建列舉，直接寫入 |

### 大公／小公

非法定用語，來自銷售與公設比計算的實務：

- **大公**：服務全棟的共用部分（屋頂突出物、機電機房、蓄水池、管理室、消防設備空間）
- **小公**：僅服務單一樓層的共用部分（該層電梯間、樓梯間、走廊）

因為不是法定分類，**必須標示為實務慣例**，且各案的分攤方式可能不同，不可當成
法規結論輸出。

---

## 三、Area Type（Revit 內建）

**Area Type 只存在於內建的「總建築面積」面積計畫。** 自訂面積計畫沒有這個參數。

- 判斷方式：`AreaScheme.IsGrossBuildingArea` 為 `True` 才有 Area Type
- 參數：`BuiltInParameter.AREA_TYPE`（值）與 `AREA_TYPE_TEXT`（可讀文字）
- 上述 API 事實經 RevitAPI.dll metadata 反射確認，**Revit 2020 與 2024 相同**

在自訂面積計畫上尋找 Area Type 會一無所獲——那不是資料缺漏，是那個計畫本來就
沒有這個概念。工具應直接說明，而非回報「讀不到」。

---

## 四、寫入哪裡

專有／共用**不是 Revit 概念**，沒有內建參數。它必須寫進專案自訂參數，而各家
事務所的參數命名不同（「屬性」「權屬」「專有共用」「面積歸屬」都見過）。

依 [user-specified-runtime-parameters.md](user-specified-runtime-parameters.md)：
**參數名稱與可接受的值一律由使用者在執行時指定，不得寫死。**

---

## 五、標準流程

1. 選面積計畫與樓層。
2. 選要寫入的參數（專有／共用），以及大公／小公若另有欄位。
3. 工具依關鍵字提出**建議**分類，並逐筆顯示判定理由與命中的關鍵字。
4. **人工覆核**：清單需可逐筆改判，且預設不覆寫已有值。
5. dry-run 預覽 → 單一 Transaction 寫入，全有全無。
6. 若面積計畫為「總建築面積」，另可一併設定 Area Type。

### 輸出必須包含的免責

> 本分類為依名稱關鍵字提出之**建議**，非法律認定。專有／共用之最終認定依區分
> 所有權登記與規約；約定專用、約定共用依其約定，無法由模型判定。

## 六、常見錯誤

| 錯誤 | 後果 |
|---|---|
| 拿「共用空間關鍵字清單」當判準 | 與條文的定義方向相反（共用是專有的補集），清單漏一項就整批錯 |
| 自動標記約定專用／約定共用 | 憑空產生法律狀態；定義上那來自約定而非空間性質 |
| 把大公／小公當法定分類輸出 | 那是實務慣例，各案分攤不同 |
| 在自訂面積計畫找 Area Type | 找不到不是缺漏，是該計畫沒有這個概念 |
| 覆寫已填好的權屬欄位 | 那些多半是人工判定過的結果，比工具的猜測可信 |
