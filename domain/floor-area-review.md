# 容積檢討流程

## 前置條件
- Revit 模型已開啟
- MCP 服務已啟動
- 房間邊界已正確繪製

## 執行步驟

### 步驟 1：取得樓層資料

```
使用工具：get_all_levels
目的：取得所有樓層清單
預期結果：樓層名稱、樓層高程
```

### 步驟 2：取得房間資料

```
使用工具：get_rooms_by_level
參數：level = 每個樓層名稱
目的：取得每層的房間清單
預期結果：房間名稱、面積、中心點座標
```

### 步驟 3：分類房間

根據房間名稱或用途分類：

| 類型 | 計入容積 | 範例 |
|-----|:-------:|------|
| 主要空間 |  100% | 住宅、辦公、商業 |
| 陽台 |  50% | 露台、陽台 |
| 附屬空間 |  0% | 機房、樓梯間、電梯間 |

### 步驟 4：計算面積

公式：
- 總樓地板面積 = Σ(計入容積的房間面積)
- 容積率 = 總樓地板面積 / 基地面積 × 100%

### 步驟 5：法規比對

參考 `domain/references/building-code-tw.md` 中的容積率規定。

常見標準：
- 住宅區：容積率 ≤ 300%
- 商業區：容積率 ≤ 600%
- 工業區：容積率 ≤ 200%

### 步驟 6：產生報告

輸出格式：

```
┌────────────────────────────────────┐
│          容積檢討報告               │
├────────────────────────────────────┤
│  一樓：XXX㎡                        │
│  二樓：XXX㎡                        │
│  三樓：XXX㎡                        │
│  ────────────────                  │
│  總計：XXX㎡                        │
│  基地面積：XXX㎡                    │
│  容積率：XXX%                       │
│  法規上限：XXX%                     │
│  結果： 符合 /  超過             │
└────────────────────────────────────┘
```

## 範例對話

**用戶**：幫我做容積檢討

**AI**：好的，我會執行容積檢討流程...

（依上述步驟執行並產生報告）

## 注意事項

1. **陽台面積**：依法規可能只計入 50%，需確認當地規定
2. **地下室**：通常不計入容積，但需檢查法規
3. **機械層**：高度超過一定標準可能需計入
4. **樓梯間**：各層重複計算或只算一次，依法規而定

## 地下層命名通則

當本 Domain 或使用者提到「地下層」時，預設指所有地下樓層：

```text
B1F、B2F、B3F、B4F、B5F ... BnF
```

專案實際命名可為：

```text
A-B1、A-B2、A-B3、A-B4、A-B5 ... A-Bn
```

地下層層數依專案實際樓層清單判定，不固定只到 B3F。

`FN` 屬於基礎/筏基層，不自動視為地下層樓層，因此不可放進「地下層各層」的樓高型計算，例如地下室外牆防水毯分層樓高或室內施工架排除樓層。

但在「大底防水 / 底版防水」中，若模型有 `FN`、`A-FN`、筏基、基礎底版或大底相關樓板，且該構件代表地下室最下方防水底版，則應納入大底防水水平投影聯集；這是因為它屬於大底防水構件，而不是因為它被視為地下層。

## 防水與施工架算量口徑速記

| 項目 | 主要公式 | FN 口徑 |
|------|----------|---------|
| 大底防水平面投影 | `Union(B1F/B2F/.../BnF 相關底板 + FN/筏基/基礎底版 XY 投影)` | 若代表筏基、基礎底版或大底樓板，需納入水平投影聯集 |
| 大底防水正式面積 | `水平投影聯集 + 坑洞展開 + 周邊上翻 + 高低差側面 + 圖說補強/收頭` | 筏基側面、大底高低差側面等列正式加項 |
| 地下室外牆防水毯 | `Σ(B1F/B2F/.../BnF 外部周長 × 樓層高度或防水高度)` | 不列入地下層分層高度；若有基礎側面防水，另列加項 |
| 室外施工架 | `外部周長 × 施工架高度` | 依 `domain/scaffold-takeoff.md`，不作為地下層樓層 |

## 大底防水水平投影面積規則

### 適用範圍

當使用者提到「大底防水」「底板防水」「地下室底版防水層」「地下層樓板防水算量」時，先採用本節規則。

### 核心定義

大底防水概算以地下層底板與 `FN` / 筏基 / 基礎底版的**水平投影聯集面積**為準，不是所有地下層樓板面積的單純加總。

公式：

```text
大底防水水平投影面積
= Union(地下層 B1F/B2F/.../BnF 相關底板 + FN/筏基/基礎底版的 XY 水平投影)
```

也就是：

```text
地下層 B1F/B2F/.../BnF 相關底板面積 + FN/筏基/基礎底版面積
- 不同樓層或不同高程樓板在 XY 平面上的重疊面積
```

### 計算步驟

1. 取得 `Floors` 類別，讀取精確欄位名稱：`樓層`、`面積`、`周長`、`頂部高程`、`底部高程`、`厚度`、`距樓層的高度偏移`。
2. 篩選大底防水底版範圍，包含 `B1F/B2F/.../BnF` 或專案實際命名如 `A-B1`、`A-B2`、`A-B3`、`A-B4` 的相關底板；若模型存在 `FN/A-FN`、筏基、基礎底版或大底相關樓板，也應納入水平投影聯集。
3. 排除明顯不是大底防水基準面的完成面、導盲磚、飾材、草地、界石、金屬包板、屋頂防水等非底板構件；若無法判斷，需在結果中列為待確認。
4. 將保留樓板轉為 XY 水平投影後做聯集，重疊區只計一次。
5. 若無幾何布林或面域聯集工具可用，需至少用樓板幾何 BoundingBox、ElementId、樓層、高程、面積做重疊審核，並把「已扣除重疊」與「待確認重疊」分開列示。

### 不可直接採用的算法

- 不可直接把 `B1F/B2F/.../BnF` 的所有樓板 `面積` 加總當作大底防水面積。
- 不可把不同高程但 XY 平面完全或部分重疊的樓板重複計入。
- 不可因 `FN` 不屬於地下層，就漏算代表筏基、基礎底版或大底的 `FN/A-FN` 樓板。
- 不可把坑洞、電梯坑、廢水坑、集水坑的展開面積混入「水平投影面積」欄位；坑洞展開面應另外列為正式算量加項。

### 正式算量延伸

若圖說要求正式防水數量，不只算水平投影，應另外檢討並分欄加計：

```text
正式大底防水面積
= 水平投影聯集面積
+ 坑洞展開面積
+ 周邊上翻面積
+ 大底高低差側面展開面積
+ 圖說指定收頭、補強或搭接範圍
```

輸出時應分成至少兩個欄位：

| 欄位 | 定義 |
|------|------|
| 大底防水平面投影 | B1F/B2F/.../BnF 相關底板 + FN/筏基/基礎底版 XY 投影聯集，重疊不重複計 |
| 大底防水正式加項 | 坑洞側面、周邊上翻、高低差側面、圖說補強與收頭 |

### 回報格式

回報需列出：

- 納入計算的樓板 ElementId、樓層、類型、面積
- 被排除的樓板 ElementId 與排除原因
- 重疊扣除面積或重疊判斷依據
- 最終水平投影面積
- 是否另有坑洞展開、上翻、高低差側面尚未加計

## 地下室外牆防水毯面積規則

### 適用範圍

當使用者提到「地下室外牆防水毯」「外牆防水毯」「地下外牆防水」「地下室牆面防水層」時，採用本節規則。

### 核心定義

地下室外牆防水毯以地下層各層外牆外部周長乘以該層樓層高度計算。

公式：

```text
地下室外牆防水毯面積
= Σ(地下層各層外部周長 × 該層樓層高度)
```

地下層範圍：

```text
B1F、B2F、B3F、B4F、B5F ... BnF
```

或專案實際命名：

```text
A-B1、A-B2、A-B3、A-B4、A-B5 ... A-Bn
```

### 外部周長來源

外部周長沿用 `domain/scaffold-takeoff.md` 中 `框式施工架(含防護設施)<室外施工架>` 的外部周長口徑。

優先順序：

1. 若使用者已用 detail line 或 filled region 描出框式施工架外部範圍，優先使用 `calculate_selected_detail_line_perimeter` 的周長結果。
2. 若沒有人工描繪線，才使用自動外牆偵測或其他可追溯工具估算外部周長。
3. 每一個地下層都必須分層列示外部周長，不可把不同地下層的周長混成單一值後不說明樓高來源。

### 樓層高度來源

樓層高度應優先使用相鄰樓層標高差。地下層依標高由上到下排序，逐層計算：

```text
B1F 樓層高度 = 1F 或 GL 標高 - B1F 標高
B2F 樓層高度 = B1F 標高 - B2F 標高
B3F 樓層高度 = B2F 標高 - B3F 標高
...
BnF 樓層高度 = B(n-1)F 標高 - BnF 標高
```

若圖說指定防水做到其他高度，例如只做到地坪下、筏基頂、GL、收頭高度或擋土牆特定高程，應以圖說指定高度優先，並在報告中註明。正式回報時欄位名稱仍以「樓層高度/防水高度」清楚標示，避免與施工架高度混用。

### 計算步驟

1. 取得樓層清單與標高，確認所有地下層 `B1F/B2F/.../BnF` 或專案實際地下層命名。
2. 取得每一個地下層的外部周長，優先沿用框式施工架外部周長。
3. 依樓層標高差或圖說指定值決定該層樓層高度/防水高度。
4. 分層計算：`外部周長 × 樓層高度`。
5. 合計各地下層外牆防水毯面積。

### 不可直接採用的算法

- 不可使用房間內周長代替地下室外牆外部周長。
- 不可使用大底防水的水平投影面積代替外牆防水毯。
- 不可把 `FN` 納入地下室外牆防水毯的「地下層各層」範圍；若圖說要求基礎層、筏基側面或大底側面防水，需另列正式加項，不混入 B1F 到 BnF 的分層小計。
- 不可只給總面積而不列出各層外部周長與樓高來源。

### 回報格式

| 樓層 | 外部周長來源 | 外部周長 m | 樓層高度/防水高度 m | 面積 m2 | 備註 |
|------|--------------|------------|------------|---------|------|
| B1F | 框式施工架外周長 | P1 | H1 | P1 × H1 |  |
| B2F | 框式施工架外周長 | P2 | H2 | P2 × H2 |  |
| ... | 框式施工架外周長 | ... | ... | ... |  |
| BnF | 框式施工架外周長 | Pn | Hn | Pn × Hn |  |

最後輸出：

```text
地下室外牆防水毯總面積 = Σ(B1F 到 BnF 各層面積)
```
