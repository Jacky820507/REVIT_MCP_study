# CAD 排水比對功能狀態

目前為**唯讀第一階段**，不是已完成全案檢核或自動出圖。

## 已實作

- `scan_drainage_cad`：明確指定圖紙或視圖，盤點來源 CAD、樓層、母視圖、座標轉換；選擇圖層後讀完整圓或互補半圓。圓半徑只作圖示尺寸。
- `preview_drainage_review`：讀回原圓心，以已核對的實際外徑/落水頭占用直徑與高度範圍檢查指定建築品類和連結。實體交集與未確認的外包框候選分開列出。公稱吋數不等於外徑。
- 接續方向 `up/down/both/unknown` 與判讀證據；上層往下、下層往上才是方向相容候選。最近的「已提供」標高不代表實際相鄰樓層，也不代表已確認同一支管。
- `bridge/python/skills/drainage_symbols.py`：獨立的唯讀 DXF 盤點器，讀巢狀圖塊、圈、文字、屬性與來源 handle。分類使用有證據的專案圖例規則，不使用通用 RP 名稱猜測。輸出仍為來源 CAD 座標，尚未自動配對至 Revit。

## 仍待完成／不能宣稱通過

- 實機 CAD 轉換、圖層與非矩形／分割裁剪確認；圓心目前僅依裁剪外包框粗篩。
- DWG 轉換與文字引線關聯、同心圈去重、網格與方向標誌辨識。DXF 盤點器不自動轉換或改動原 DWG。
- 屋突落水頭的天溝有效集水區、坡向與出水接管路徑；目前明確回報待確認，不依構件外包框判定落在天溝。
- 完整符號模板、跨層接續確認、可失效的審查憑證、標註持久去重，以及交易式原生細部線／文字繪製。因此尚未註冊任何 drainage 寫入工具。

## 下一次實機驗證

先保存並關閉 Revit，再部署同版本外掛並重新啟動 Revit/MCP。先以單一已確認排水視圖 `includeCircles=false` 盤點來源，再指定圖層抽圓。核對數個圓心與來源文字、圖例、母視圖後才擴大範圍。未知方向、未知外徑、缺天溝區域，不得改寫成「無衝突」。
