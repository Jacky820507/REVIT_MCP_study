## [L-031] Excel 同步不可用「使用者可改的欄位」當身份主鍵

- **規則**：Revit ↔ Excel 逐列同步時，身份主鍵必須是穩定識別碼（`ElementId`），不是房間編號或名稱。編號會重編、名稱會改，兩者都是使用者隨時可改的欄位。做法是在表上保留一欄 `RevitId` 由工具自動維護，並採多階段匹配：① Id →②編號＋名稱 →③名稱＋數值（容差先嚴後寬）→④名稱唯一。四階段都對不上但數值吻合者（疑似改名與重編同時發生）標記 `unresolved` 不寫入，交人工裁決。
- **避坑經驗**：案例——使用者刪除一間機房並把 31 間房整批重編號。當時工具以「編號」為身份鍵，於是把每一列改寫成「該新編號的目前佔用者」：空間表本身看起來完全正確，但下游分頁（踢腳、內牆、地坪、天花）的手填資料全部錯位一格，且錯得很安靜。修復方式是還原備份、改用 `ElementId` 為主鍵重新同步。改用 `ElementId` 主鍵後重驗同一批資料：重編號全數識別、真新增與真拆除各自正確分類、無誤判。
- **實踐**：重編號要「就地改編號欄、列位不動」，下游手填資料才會跟著房間本體走。任何以使用者可改欄位當主鍵的同步設計都有此風險，不限於 Excel。
- **延伸**：`domain/room-space-table-sync.md`。

## [L-032] 既有活頁簿是合約——插列安全，刪列會製造 `#REF!`

- **規則**：更新既有估價活頁簿時，畫面上的總數只是最後一步；真正的合約包含列標籤、公式、倍數欄、跨分頁參照與人工維護欄位。在 Excel「插入」列時，所有分頁的固定引用（`='空間表'!B50` → `B51`）會自動位移修正，零錯位；「刪除」列則讓引用變 `#REF!`。因此新增資料用插列，移除資料絕不可直接刪列。
- **避坑經驗**：若確實需要移除（例如保留墓碑列會造成編號重複，如已拆除的房號與遞補的新房號並存），安全程序是：① 全簿掃描該列的所有引用（含嵌在運算式中的）；② 確認引用全部落在各分頁「該筆的主列＋明細列」區塊內，才依序刪下游區塊、再刪主表列；③ 刪列後若緊接列出現**裸 `#REF!`**（遞增序號類公式 `=A22+1` 斷鏈）自動重指向上一列同欄修復，帶分頁前綴的舊傷不碰；④ 一旦偵測到區塊外的殘留引用就**不刪**，退回墓碑保留並回報殘留位置。依此程序連動刪除後，全簿 `#REF!` 數量與基準完全相同（零新增破壞）。
- **實踐**：寫入前必先備份（同資料夾時間戳副本）並 dry-run 預覽差異；目標檔若正被開啟（唯讀鎖定）一律中止，不得寫入。
- **延伸**：`domain/revit-excel-workbook-update.md`、`domain/room-space-table-sync.md`。

## [L-033] 公式儲存格要走白名單，但白名單失敗只擋寫入、不擋預覽

- **規則**：只檢查「這格有沒有公式」不夠。寫入數量或倍數欄前，要先把公式正規化（去空白、`$`、工作表引號），再比對預期的公式形狀，例如 `=Frow*Grow`、`=PRODUCT(Frow,Grow)`。含額外參照、條件式、跨列加總或連到無關工作表的公式一律拒絕，除非該活頁簿樣式已被明確審查過。
- **避坑經驗**：兩個常見情境。其一，目標數量欄本身可能就是應保留的公式——基數或無障礙數量可能由其他列、其他分頁帶入；不能因為本次重算結果剛好等於模型數量就放行覆寫。其二，某列 F 欄是 `=SUM(F9:F12)*2` 這種「合計 × 倍率」公式，F 欄已含倍率，若工具又把 G 欄寫成 2，`H=F*G` 會再乘一次造成數量翻倍；正解是保留 F 欄公式、驗證內含倍率等於使用者選擇、G 欄寫入 1。
- **實踐**：公式白名單失敗應**阻擋寫入但不阻擋預覽**。預覽仍要列出模型數量、目標列、舊值與實際公式，讓使用者先確認數量是否合理，再決定要修公式還是擴充白名單。直接跳錯結束會讓使用者失去判斷依據。
- **延伸**：`domain/revit-excel-workbook-update.md`。

## [L-034] 樓層排序不可用字串排序，棟別前綴不可當地下層代碼

- **規則**：所有分樓層報表依建築閱讀順序排列——地下層由深到淺（`B5F→B1F`）、地上層由低到高（`1F→2F→…→10F`）、屋突層由低到高且 `RF` 排在所有 `R#F` 之後、未解析樓層排最後並標示待人工確認。排序前先正規化成樓層鍵，不得用字串排序（否則 `10F` 會排在 `2F` 前），也不得用 Excel 範本既有列順序（會漏掉專案實際存在的地下層或屋突層）。
- **避坑經驗**：案例——某專案 Level 命名為 `B-B1F`、`B-1F`、`B-R1F`，其中 `B-` 是**棟別**前綴。若粗暴移除連字號，`B-1F`（地上 1F）會變成 `B1F` 被錯排成地下 1F。正確作法是先從同批 Level 是否存在 `B-B1F`／`B-R1F` 來確認 `B` 是棟別，再移除共同前綴解析真正樓層；沒有棟別證據時，`B-1F` 才依一般寫法正規化為 `B1F`。不可單看字首 `B` 就決定。
- **實踐**：彙總分頁的樓層數量欄應以公式引用明細分頁的樓層小計（例如 `='數量明細'!W10`），不要只填常數——保留公式鏈才追溯得到來源，也避免範本殘值造成重算錯誤。
- **延伸**：`domain/floor-level-ordering.md`。

## [L-035] 明細表、類別、連結模型是三種不同的數量邊界

- **規則**：取數前先決定來源邊界。使用者指定明細表時，就只收集該命名明細表中的元素並以 `ElementId` 去重，不可偷換成原始類別收集——原始類別常混入符號、箭頭、輔助圖形或佔位元素（`OST_Parking` 常會抓到行車方向標誌與箭頭族群）。只有當類別本身就是目標範圍時才用類別收集。
- **避坑經驗**：共用地下室或多棟專案的數量可能不在 host document，需要讀 Revit 連結模型，而這是**第三種**邊界。讀連結時：`ElementId` 去重要帶上 link instance id（跨文件會重複）；樓層比對不能用 host `LevelId`，需改用樓層名稱或高程。更關鍵的是，**不可把主模型明細表的參數篩選直接套到連結模型**——假設主模型用「標註＝汽車停車」篩選，但連結模型的同名欄位存的是 `701`、`702` 這類車位編號，照套會把全部連結車位錯誤排除。同一樓層有多個連結時必須讓使用者明確複選連結實例，不可用「包含全部連結」代替。
- **實踐**：來源明細表清單不要過度關鍵字過濾（專案命名常有縮寫、英文、代碼或分包前綴）；列出所有非樣板 ViewSchedule，把候選排前面並預選，但仍讓使用者選得到任何實際存在的明細表。預覽要列出每個來源實際納入的數量。
- **延伸**：`domain/revit-excel-workbook-update.md`、`domain/quantity-takeoff-excel.md`。

## [L-036] 房間相鄰不等於開口位於該房間的計算邊界

- **規則**：門窗的 `FromRoom`／`ToRoom` 只能證明開口與房間有關，**不能**證明其宿主牆屬於該房間的粉刷或踢腳邊界。扣除開口前，必須先取得 `GetBoundarySegments(Finish)` 的宿主元素集合，再確認門窗宿主牆的 `ElementId` 位於該集合內。
- **避坑經驗**：案例——某房間旁的「廁所門」若其所在隔牆並非該房間的計算邊界，就不得扣除。同理，房間型算量的周長應累加 `GetBoundarySegments(Finish)` 回傳的**全部**邊界迴圈，只取第一圈會漏掉內圈、柱洞或房間包覆的其他空間；直接用 Revit `ROOM_PERIMETER` 則可能是牆中心線值，與實際裝修面語意不符，只能在 boundary API 無資料時當作**明確標記**的備援。
- **實踐**：Excel 的名稱欄採 Revit 門窗類型名稱，但扣除資格由宿主與邊界關係決定——不能因類型名稱含「廁所門」就一律扣除或排除。另外，完整房間明細與「有數量的項目」是兩個不同集合：沒有踢腳或粉刷的房間其數量可為 0 或空白，但房間列不可因此刪掉。
- **延伸**：`domain/quantity-takeoff-excel.md`。

## [L-037] 部分來源的數量不可直接覆寫全案小計

- **規則**：當使用者只勾選部分連結模型或部分樓層時，若把該子集的數量直接寫進小計欄，其他棟別或樓層的既有數量就被靜默洗掉。正確作法是另建「稽核」分頁當帳本，每列記錄 `來源模型｜樓層｜識別鍵｜名稱｜數量｜更新時間`，小計欄寫各來源加總後的**純數字**。
- **避坑經驗**：案例——某型號全案 22 樘，使用者只勾單一連結的單一樓層執行，結果 6 樘覆蓋了 22 樘。改用帳本後：重跑同一個 `(模型, 樓層)` 只取代它自己那幾列，具冪等性不會重複累加；未套用樓層篩選的整模型執行範圍記為「全部樓層」，且必須清掉該模型所有既有分層列，否則舊分層數會疊在整模型數之上。
- **實踐**：小計欄刻意**不**寫 `SUMIF` 跨表公式——「只覆寫純數字」是這類工作流的安全規則，寫成公式會讓下一次執行判定為受保護而自我阻擋。另外，兩個方向的落差都要回報：Excel 有工項但模型沒有該型號時**不得歸零**（可能是連結沒勾或該型號在別的分區），只列出待確認；模型有但 Excel 沒有對應列時，列出型號與數量提示人工新增。
- **延伸**：`domain/quantity-takeoff-excel.md`。
