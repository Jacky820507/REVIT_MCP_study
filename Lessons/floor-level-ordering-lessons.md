# 樓層排序 Lessons

## L-001：樓層排序不可使用字串排序或 Excel 範本列順序

使用者指定 `其他面積` 樓層順序應為 `B1F、1F、2F、3F、4F、5F、6F、R1F、R2F`，並補充通則為地下層後接地上層再接屋突層。若用一般字串排序，`10F` 會排在 `2F` 前；若依 Excel 範本既有列順序，會漏掉 Revit 專案實際存在的地下層或屋突層。正確作法是先正規化樓層鍵，再依 `B深→B1F→1F→...→R1F→R2F→RF→未知` 排序。

## L-002：彙總分頁要保留明細索引公式

施工架 `施工架計算` 分頁已逐房完成 `周長×高` 或 `長×寬×高`，`其他面積` 不應再二次相乘；但如果 `其他面積` 只填常數，使用者難以追溯來源。正確折衷是先在 `施工架計算` 建立樓層小計欄，再讓 `其他面積` 的樓層數量欄引用該小計儲存格，例如 `='施工架計算'!W10`。這保留公式鏈與可稽核性，同時避免模板殘值造成重算。

## L-003：棟別前綴不能當成地下層代碼

物流中心的 Revit Level 使用 `B-B1F`、`B-1F`、`B-R1F` 表示 B 棟地下 1F、地上 1F、屋突 1F。若先粗暴移除連字號，`B-1F` 會變成 `B1F`，把地上 1F 錯排成地下 1F。應先從同批 Level 的 `B-B1F` 或 `B-R1F` 確認 `B-` 是棟別，再移除共同前綴並解析真正樓層。
